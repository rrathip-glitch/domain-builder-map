# Shared research tips (living file: read at start, append when you learn something)

Every research agent reads this before starting and appends one line when it finds a trick that would save the next agent time, or a trap that cost it time. Append with a single shell command so parallel writers do not clash:

```
echo "- [your-builder-id] the tip, in one line" >> /Users/rathiprajakumar/Desktop/RWorks/domain-intel/TIPS.md
```

Keep tips general enough to help on other builders (a source type, a URL pattern, a search phrasing, a tool quirk). Do not log findings about your own builder here.

## Starting tips (from the orchestrator)

- EDGAR: `curl -s -H "User-Agent: domain-intel-research/1.0 (research use)" "https://data.sec.gov/submissions/CIK##########.json"` lists every filing for a company (10-digit zero-padded CIK). Find the CIK with `https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&company=NAME&type=10-K&output=atom`. Keep to 2 requests per second.
- The 10-K "Information about our Executive Officers" section plus the proxy (DEF 14A) give officers with ages and tenure; 8-K Item 5.02 gives changes since. The lots table (owned vs optioned/controlled) is in Item 1 or Item 2 of the 10-K and updated in each 10-Q and earnings release.
- Earnings press releases (8-K exhibit 99.1) usually carry the freshest lot counts and liquidity; the debt footnote in the latest 10-Q carries every notes series.
- Division presidents: company "where we build" / division pages, local business journals, HBA/BIA board lists, and "names/promotes ... division president" press releases. Search `"<builder>" "division president" <metro>` for the builder's main metros.
- Land heads: titles vary ("VP of Land", "Land Acquisition Manager", "Director of Land", "Chief Investment Officer", "President of Land"). Search each phrasing.
- Large pages: if WebFetch truncates a long filing, fetch with curl to the scratch dir and grep for the section you need.
- Never open linkedin.com. Never cite it.
- Write your JSON early and keep it valid; run the validator before finishing.
